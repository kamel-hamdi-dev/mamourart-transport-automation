# Mamourart Transport Automation

AI-powered transport automation project designed to simplify daily operations for transport companies.

## 🚀 Project Goal

The goal is to automate repetitive transport-management tasks such as:

- Processing incoming transport emails
- Extracting mission information
- Organizing driver schedules
- Managing transport assignments
- Automating daily workflows

## 🛠 Technologies

- Python
- REST APIs
- PostgreSQL
- AI Automation
- Workflow Automation
- Git & GitHub

## 📌 Status

🚧 Currently under development.

This project is being developed as a real-world portfolio project under Mamourart.
